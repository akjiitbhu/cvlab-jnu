# Course files

Put PDFs, notebooks and datasets here, then reference them from a course's
**materials** rows in the admin portal.

A file saved as `public/files/dip/unit1-slides.pdf` is served at
`/files/dip/unit1-slides.pdf` — that is the value to paste into the URL field.

Suggested layout, one folder per course slug:

    files/cp/     Computer Programming
    files/ds/     Data Structure
    files/dbms/   Database Management Systems
    files/dip/    Digital Image Processing

Keep files modest in size; Git is a poor store for very large binaries. Link to
Drive or an institutional store for big datasets.
